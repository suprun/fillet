# Інструкції для AI-асистента

## Загальні правила

- Відповідай українською мовою.
- Пиши код у стилі, який уже використовується в проєкті.
- Не змінюй архітектуру без явної потреби.
- Не видаляй існуючий функціонал без пояснення.
- Перед великими змінами коротко пояснюй план.
- при кожному внесенні змін коду інкременуй в metadata.txt   номер білда (четверта цифра в версії) та оновлюй версію в repo\plugins.xml, перепакуй архів repo\fillet.zip без "pycache" та типів файлів із gitignore
- не ігноруй файли в проекті позначені в .gitignore
- Плагін розробляється сумісним для версій QGIS 3.16-3.99 (зокрема для інтерфейсів Qt5)

## Стиль коду

- Python: дотримуйся PEP 8.
- Назви змінних мають бути зрозумілими.
- Не додавай зайві абстракції.

## Коментарі

- Коментуй тільки неочевидну логіку.
- Не пиши коментарі типу `# increment counter`, якщо дія очевидна з коду.

## Тестування

- Підтримуй крос-версійну працездатність тестів для цільових середовищ (зокрема сумісність PyQt5 та PyQt6).
- При додаванні або зміні функціоналу обов'язково оновлюй або дописуй відповідні модульні тести.
- Тести мають покривати критичні аспекти плагіна:
  - **Геометрія та алгоритми:** коректність обчислень, граничні випадки (гострі/тупі кути, короткі сегменти, замкнені/розімкнені контури, метричні та географічні CRS у градусах).
  - **Життєвий цикл плагіна:** ініціалізація інтерфейсу (`initGui`), коректне вивантаження (`unload`), відсутність витоків пам'яті та повторне відкриття без дублювання UI-елементів.
  - **Стан і налаштування:** збереження/відновлення параметрів (`QgsSettings`), адаптація діапазонів і точності до систем координат.
  - **Локалізація:** валідність файлів перекладу (`.qm` / `.ts`) та коректність завантаження перекладів для активної локалі.
- Дотримуйся ізоляції тестів: акуратно ініціалізуй та очищуй ресурси `QgsApplication` / `QgsMapCanvas`, скидай тестові налаштування після завершення тестів.
- Перед фіксацією змін обов'язково запускай smoke-тести для перевірки працездатності в усіх доступних версіях середовища.

## Правила роботи з промптами

- Plan mode: / планування: - режим планування без редагування коду
- Ask mode: / запитання: - режим відповідей на запитання асистентом без редагування коду

## Безпека

- Не виводь секретні дані в лог.

## Git

- Не змінюй файли, які не стосуються задачі.
- Не форматуй увесь проєкт без потреби.
- Уникай великих не пов’язаних між собою змін.

AI не повинен читати, аналізувати, змінювати або пропонувати зміни для таких файлів і папок, якщо користувач прямо не просить:

- `.env`
- `.env.*`
- `node_modules/`
- `.venv/`
- `venv/`
- `dist/`
- `build/`
- `__pycache__/`
- `*.pyc`
- `*.zip`
- `repo/` — власний plugin repository для qgis
